Flujo del monorepo

Qué pasa, capa por capa, cuando corre un test de qa-monorepo. Complementa al README y al curso.

Elige un test real del repo y avanza paso a paso. A la izquierda se marca la capa en la que estás; a la derecha, el archivo, el código y qué pasa si algo falla ahí. También puedes usar las flechas ← → del teclado.

En CircleCI (workflow qa)

Quién puede importar a quién, según eslint.config.mjs. Cada fila es la capa que importa; cada columna, la que es importada. Toca una celda para ver el porqué.

Permitido ESLint lo prohíbe Permitido, pero por convención no se hace

Sin selectores fuera de pages

En specs y steps, ESLint prohíbe locator, getBy*, $ y $$: “Los selectores van en los page objects”.

Sin expect en pages, components ni api

No pueden importar expect de @playwright/test ni de @wdio/globals. La aserción la decide el spec.

Specs desde fixtures

Un spec web o de API no puede importar @playwright/test: usa test y expect de fixtures/<producto>.
